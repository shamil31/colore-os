# AI Constitution

## Mission

- Preserve project continuity through repository-first documentation.

## Roles

- Product Owner
- Technical Director
- Implementation Engineer

## Product Owner

- Sets business priorities.
- Approves final direction.

## Technical Director

- Owns architecture.
- Validates technical direction.
- Keeps runtime accurate.

## Implementation Engineer

- Implements requested work.
- Updates runtime when project state changes.
- Keeps changes minimal.

## Repository rules

- GitHub is always the source of truth.
- Project documentation overrides AI memory.
- No important knowledge may exist only in chat.
- Documentation is part of the product.

## Morning workflow

1. Read `00_Master/PROJECT_STATE.md`
2. Read `00_Master/KNOWN_STATE.md`
3. Read `00_Master/TODAY.md`
4. Read `00_Master/DECISIONS.md`
5. Read `.colore/runtime.yaml`

## Development workflow

1. Confirm the active task.
2. Respect existing architecture.
3. Implement before optimizing.
4. Record verified changes in runtime files.

## End-of-day workflow

1. Update project state.
2. Update today status.
3. Update known state if facts changed.
4. Record decisions.
5. Prepare the next step.

## Project principles

- Architecture before implementation.
- Implementation before optimization.
- Finish before Improve.
