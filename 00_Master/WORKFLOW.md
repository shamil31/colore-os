# WORKFLOW

## Morning command

`@GitHub Начинаем день`

## Workflow

1. `git pull`
2. Read `PROJECT_STATE.md`
3. Read `KNOWN_STATE.md`
4. Read `TODAY.md`
5. Read `DECISIONS.md`
6. Read `.colore/runtime.yaml`
7. Continue current task
8. Never restart completed work

## Evening command

`Закрываем день`

## Workflow

1. Update `PROJECT_STATE.md`
2. Update `TODAY.md`
3. Update `KNOWN_STATE.md` if needed
4. Record architecture decisions
5. Prepare tomorrow
6. Commit
7. Push

## Project rule

Finish before Improve.
