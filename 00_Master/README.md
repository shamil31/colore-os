# Runtime

Coloré Development OS stores the active project runtime in this directory.

Every work session starts by reading:

1. `PROJECT_STATE.md`
2. `KNOWN_STATE.md`
3. `TODAY.md`
4. `DECISIONS.md`
5. `BACKLOG.md`
6. `WORKFLOW.md`

GitHub is the Single Source of Truth.

Use `.colore/runtime.yaml` as the machine-readable runtime for automation.
