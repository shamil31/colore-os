# .runtime: Project Runtime Configuration

**Purpose:** Live project state, session management, and execution context.

This directory contains:
- Session logs and state
- Runtime configuration
- Agent task assignments
- Real-time project metrics

## Files

- `README.md` - This file
- `CURRENT_SESSION.json` - Active session metadata
- `TASK_QUEUE.json` - Current work assignments
- `STATE_SNAPSHOT.json` - Project state snapshot

These files are updated during execution and reflect real-time project state.
