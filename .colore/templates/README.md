# Templates

Reusable document skeletons that keep new Runtime, ADR, and playbook documents consistent with Runtime v1.

- [`adr-template.md`](adr-template.md) — new Architecture Decision Records
- [`playbook-template.md`](playbook-template.md) — new operating playbooks

Use these instead of copying an existing document — copying an existing document tends to carry over content that belongs only to that document, violating One Document = One Responsibility (`docs/adr/ADR-0003-One-Document-One-Responsibility.md`).
